Paperboard web flasher

Installs the Paperboard firmware on a blank or old display board directly from this page. Later updates come over Wi-Fi from the Paperboard Homey app, so you only need this page once per board.

1. Check your browser

Use Chrome or Edge on a computer (Windows, macOS, Linux). Safari, Firefox, iPhones and iPads do not support Web Serial. Use a USB cable that carries data, not a charge-only cable.

2. Install

WeMos D1 mini (ESP8266) with a 4.2" b/w panel

This browser cannot flash. Use Chrome or Edge on a computer. This page must be opened over HTTPS or from localhost.

  • Pick the port USB-SERIAL CH340. Some systems need the CH340 driver first (USB id 1a86:7523).

NM-EPD-420 (ESP32-S3) with a 4.2" b/w/red panel

This browser cannot flash. Use Chrome or Edge on a computer. This page must be opened over HTTPS or from localhost.

  • Put the board in download mode first: hold BOOT, press RESET, release BOOT. Then pick the port that appears (USB JTAG/serial).
  • If the board does not restart after flashing, press RESET.

Notes

  • Tick Erase device only for a first install or for a board that ran other firmware. Erasing removes the Wi-Fi settings and the Homey pairing: afterwards delete the old device in Homey and add the display again; its layout is lost (there is no export yet).
  • To update a display that is already set up, leave Erase device unticked: Wi-Fi and pairing are kept.
  • After flashing the display (after an erase) shows Paperboard setup with a QR code. Join its Wi-Fi network and enter your home Wi-Fi there. This page cannot set up Wi-Fi, ignore a possible "Connect to Wi-Fi" prompt of the flasher.
  • The page runs entirely from this site: no external scripts, nothing is uploaded.

Without the browser (esptool)

Download the image of your board from the links below, then use esptool (esptool v5 spells the commands erase-flash and write-flash):

esptool.py --chip esp8266 erase_flash
esptool.py --chip esp8266 --baud 115200 write_flash 0x0 paperboard-d1_mini-<version>-factory.bin

esptool.py --chip esp32s3 erase_flash
esptool.py --chip esp32s3 write_flash 0x0 paperboard-nm_epd_420-<version>-factory.bin
  • paperboard-d1_mini-5.5.0-factory.bin (D1 mini, flash offset 0)
  • paperboard-nm_epd_420-5.5.0-factory.bin (NM-EPD-420, flash offset 0)
  • paperboard-firmware-5.5.0-src.tar.gz (source, GPL-3.0)
